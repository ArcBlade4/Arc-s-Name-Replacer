# Arc's Name Replacer
Arc' Name Replacer Version: 1.3

Mod Description:
This mod randomly selects non unique stalkers to give a special name taken from the names.txt file.

Installation: 
Mo2:
1. Use Mo2 to install Arc's Name Replacer.7z 
2. Place names.txt in the root of your ANOMALY directory (the same place where AnomalyLauncher.exe is)
3. Run the game

Manual:
1. Extract Arc's Name Replacer.7z and copy paste gamedata folder into root directory
2. Place names.txt in the root directory (the same place where AnomalyLauncher.exe is)
3. Run the game


MCM settings:
Spawn Chance (float 0-100)(default: 1) - Percentage chance for a stalker to be renamed.
Enable PDA Alerts (bool)(default: true) - Turn on/off PDA alerts for when a stalker is renamed.
